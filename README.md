# 📝 To-Do List App (Tkinter)

A simple desktop To-Do List application built using Python and Tkinter.

## 🚀 Features
- Add Task
- Update Task
- Delete Task
- Delete All Tasks
- Task Counter
- Simple UI with color animation

## 🛠️ Tech Used
- Python
- Tkinter

## ▶️ Run Project

```bash
python main.py
